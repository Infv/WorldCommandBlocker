# WorldCommandBlocker
PocketMine-MP plugin that blocks specific commands in configured worlds.

| World   | Command              | 
| ------- | -------------------- | 
| Lobby   | spawn                |
| Lobby   | warp                 |


| Description       | Permission |
| ----------------- | ---------- |
| get bypass        | fly.bypass |

INSTALLATION:

1. Download the latest release.
2. Place the plugin inside the `plugins/` directory.
3. Restart your PocketMine-MP server.
4. Edit the configuration if necessary.
